Segurança e acesso

Proteja o acesso ao aplicativo neste aparelho. O PIN é usado como alternativa de desbloqueio.

Quando disponível, a autenticação biométrica do aparelho poderá ser usada futuramente como complemento. Nesta etapa, o PIN é o método de acesso implementado.

Backup e recuperação

Faça um backup completo dos dados deste aparelho. O arquivo é salvo em formato JSON e pode ser guardado no Google Drive, iCloud, computador ou outro local seguro.

A restauração substitui os dados atuais deste navegador. Antes dela, o aplicativo cria automaticamente uma cópia de segurança local dos dados atuais.

Versão de teste • Um caixa por vez no dashboard e no histórico. Não use dados bancários reais nesta etapa.
